# ZuCo Eye-Tracking Experiment Results (2026-02-13)

## Background

OpenTSLM is a multimodal time-series language model that uses a Flamingo-style architecture to combine a vision/time-series encoder with a frozen LLM (Llama 3.2 3B). It is trained via curriculum learning across multiple stages on different biosignal modalities.

The ZuCo (Zurich Cognitive Language Processing Corpus) experiments evaluate the model's ability to classify **reading task type** from word-level eye-tracking metrics: Normal Reading (NR) vs Task-Specific Reading (TSR).

- **ZuCo 1.0**: 12 subjects, ~1275 test samples
- **ZuCo 2.0**: 18 subjects, ~2217 test samples

## Setup

- **Model**: OpenTSLMFlamingo (Llama 3.2 3B backbone)
- **Task**: Binary classification — Normal Reading vs Task-Specific Reading
- **Training**: batch_size=2, lr=2e-4, gradient checkpointing, cosine schedule with 3% warmup
- **Early stopping**: patience=5 epochs on validation loss (manually killed early when clearly overfitting)
- **Max epochs**: 30
- **Hyperparams**: see `src/model_config.py` (EARLY_STOP_PAT=5, WARMUP_FRAC=0.03, GRAD_CLIP_NORM=1.0)

## Results

| Init Checkpoint | ZuCo 1.0 (stage9) | ZuCo 2.0 (stage9b) |
|---|---|---|
| HAR-flamingo (HF: `OpenTSLM/llama-3.2-3b-har-flamingo`) | 69.65% | 59.59% |
| Sleep-flamingo (HF: `OpenTSLM/llama-3.2-3b-sleep-flamingo`) | 69.25% | 68.29% |
| Full curriculum (stage1→…→6→7→8→9) | 70.51% | 59.95% |
| From scratch (Llama 3.2 3B, no pretrain) | 68.63% | 62.25% |

### Details

**HAR → ZuCo 2.0** (`zuco2_har`): best epoch 1, val_loss=0.1451, 6 epochs, acc=59.59%
**Sleep → ZuCo 2.0** (`zuco2_sleep`): best epoch 3, val_loss=0.1853, 8 epochs, acc=68.29%
**HAR → ZuCo 1.0** (`zuco1_har`): best epoch 2, val_loss=0.1435, 7 epochs, acc=69.65%
**Sleep → ZuCo 1.0** (`zuco1_sleep`): best epoch 1, val_loss=0.1954, 3 epochs (killed), acc=69.25%
**Full curriculum → ZuCo 1.0** (`training_zuco_stage9_rerun`): best epoch 1, val_loss=0.1320, 6 epochs, acc=70.51%
**Full curriculum → ZuCo 2.0** (`fullcurr_zuco2`): best epoch 2, val_loss=0.1833, 3 epochs (killed), acc=59.95%
**Scratch → ZuCo 1.0** (`scratch_zuco1`): best epoch 3, val_loss=0.1386, 4 epochs (killed), acc=68.63%
**Scratch → ZuCo 2.0** (`scratch_zuco2`): best epoch 2, val_loss=0.1441, 3 epochs (killed), acc=62.25%

### Notes

- The full curriculum run loaded from `stage6_financial_reports` checkpoint (chain: stage1→2→3→4→5→6→7→8→9), so it includes both HAR and Sleep in its lineage.
- All runs show overfitting after early epochs (train loss keeps decreasing, val loss rises).
- Sleep-flamingo outperforms HAR-flamingo on ZuCo 2.0 by ~9 percentage points (68.29% vs 59.59%).
- On ZuCo 1.0, HAR and Sleep perform nearly identically (~69.5%).
- From-scratch training is surprisingly competitive: only ~1% worse than pretrained checkpoints on ZuCo 1.0 (68.63% vs 69.65%), and better than HAR on ZuCo 2.0 (62.25% vs 59.59%).
- The full curriculum achieves the best ZuCo 1.0 result (70.51%), but only ~1% above the direct checkpoint runs.
- On ZuCo 2.0, the full curriculum (59.95%) performs similarly to HAR (59.59%) — both worse than from-scratch (62.25%) and far worse than Sleep (68.29%).

- `results/metrics.json` — final test metrics (accuracy only)

### Per-class metrics (IMPORTANT for paper)

The `metrics.json` files only store overall accuracy. For the paper, **compute per-class metrics from `test_predictions.jsonl`** in each result directory:
- **Precision, Recall, F1** for each class (Normal Reading, Task-Specific Reading)
- **Macro F1** and **Balanced Accuracy**
- **Confusion matrix** (2x2)

The predictions are clean text labels: `"generated"` is `" Normal Reading"` or `" Task-Specific Reading"` (leading space), `"gold"` is `"Normal Reading<|end_of_text|>"` or `"Task-Specific Reading<|end_of_text|>"`. Parse by stripping whitespace and `<|end_of_text|>`, then lowercasing.

Class distribution in test sets:
- **ZuCo 1.0**: 550 NR (43.1%) / 725 TSR (56.9%) — majority baseline 56.9%
- **ZuCo 2.0**: 1047 NR (47.2%) / 1170 TSR (52.8%) — majority baseline 52.8%

This moderate class imbalance makes per-class metrics essential alongside accuracy.

### How to reproduce

```bash
# Example: Sleep-flamingo → ZuCo 2.0
CUDA_VISIBLE_DEVICES=0 python curriculum_learning.py \
    --model OpenTSLMFlamingo \
    --llm_id meta-llama/Llama-3.2-3B \
    --stages stage9b_et2_reading_task \
    --init_checkpoint /path/to/sleep-flamingo/model_checkpoint.pt \
    --experiment_tag zuco2_sleep \
    --batch_size 2 \
    --gradient_checkpointing

# Example: From scratch → ZuCo 1.0 (no --init_checkpoint)
CUDA_VISIBLE_DEVICES=0 python curriculum_learning.py \
    --model OpenTSLMFlamingo \
    --llm_id meta-llama/Llama-3.2-3B \
    --stages stage9_et_reading_task \
    --experiment_tag scratch_zuco1 \
    --batch_size 2 \
    --gradient_checkpointing

# Eval-only (requires existing checkpoint in results dir)
CUDA_VISIBLE_DEVICES=0 PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
    python curriculum_learning.py \
    --model OpenTSLMFlamingo \
    --llm_id meta-llama/Llama-3.2-3B \
    --stages stage9b_et2_reading_task \
    --eval_only \
    --experiment_tag scratch_zuco2 \
    --batch_size 2 \
    --gradient_checkpointing
```
