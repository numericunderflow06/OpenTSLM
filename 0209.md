## Bugs found and fixed

1. **CRITICAL — Sentiment labels 66% wrong** (`zuco_eeg_loader.py`): Index-based matching between .mat file sentences and sentiment CSV was broken because the .mat file contains sentences not present in the CSV, causing index shifts. Fixed by switching to text-based matching. **The running process (PID 2773789) still has the old buggy code in memory** — stage 7 is unaffected but stage 8 will use wrong labels. Must restart before stage 8 starts.

2. **Duplicate stage4/stage5 definitions** (`curriculum_learning.py`): `stage4_sleep_cot` and `stage5_ecg_cot` were each defined twice (methods + dispatchers). Removed duplicates.

3. **Accuracy function fragile for text labels** (`curriculum_learning.py`): `_calculate_accuracy_baseline` only compared first 3 characters, designed for MCQ "(a)"/"(b)" labels. Upgraded to 3-tier matching: exact → startswith → first-3-char MCQ fallback.

4. **EEG transpose heuristic** (`zuco_eeg_loader.py`): Used `shape[0] > shape[1]` to detect orientation. Replaced with explicit check against known channel count (105).

5. **pos_embed shape mismatch** (`curriculum_learning.py`): HF checkpoint has `pos_embed (1,1024,128)` vs model `(1,2600,128)`. Added shape-mismatch filtering in both `_load_checkpoint` and `_load_previous_stage_model` before `load_state_dict`.
