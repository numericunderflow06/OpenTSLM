## Analyzing Logs

### Python Example: Training Loss Over Time
```python
import json
import matplotlib.pyplot as plt

# Read training logs
losses = []
with open('training_log.jsonl') as f:
    for line in f:
        log = json.loads(line)
        if log['type'] == 'training_step':
            losses.append(log['loss'])

# Plot
plt.plot(losses)
plt.xlabel('Training Step')
plt.ylabel('Loss')
plt.title('Training Loss Over Time')
plt.savefig('loss_curve.png')
```

### Python Example: Accuracy by Question Type
```python
import json
from collections import defaultdict

# Read evaluation logs
by_type = defaultdict(lambda: {'correct': 0, 'total': 0})

with open('evaluation_log.jsonl') as f:
    for line in f:
        log = json.loads(line)
        q_type = log['question_type']
        by_type[q_type]['total'] += 1
        if log['is_correct']:
            by_type[q_type]['correct'] += 1

# Print results
for q_type, stats in by_type.items():
    accuracy = stats['correct'] / stats['total']
    print(f"{q_type}: {accuracy:.1%} ({stats['correct']}/{stats['total']})")
```

### Bash Example: Extract Failed Predictions
```bash
# Find all incorrect predictions
cat evaluation_log.jsonl | jq 'select(.is_correct == false) | {question_type, expected_answer, generated_answer}'

# Count by question type
cat evaluation_log.jsonl | jq -r '.question_type' | sort | uniq -c

# Get average loss per epoch
cat training_log.jsonl | jq 'select(.type == "epoch_summary") | {epoch, train_loss}'
```

## Log Schema

### Training Step Log
- `timestamp` (string): ISO format timestamp
- `type` (string): "training_step"
- `epoch` (int): Current epoch number
- `step` (int): Global step number
- `loss` (float): Training loss for this step
- `lr_encoder` (float): Current learning rate for encoder
- `lr_projector` (float): Current learning rate for projector

### Epoch Summary Log
- `timestamp` (string): ISO format timestamp
- `type` (string): "epoch_summary"
- `epoch` (int): Epoch number
- `train_loss` (float): Average training loss for epoch
- `val_loss` (float or null): Validation loss if available

### Evaluation Sample Log
- `timestamp` (string): ISO format timestamp
- `type` (string): "evaluation_sample"
- `sample_idx` (int): Sample index
- `market_id` (string): Market identifier
- `question_type` (string): Type of question
- `pre_prompt` (string): Pre-prompt text
- `time_series_info` (array): Array of time series metadata
  - `description` (string): Human-readable description
  - `length` (int): Number of data points
  - `num_patches` (int): Number of embedding patches
- `post_prompt` (string): Question/post-prompt
- `expected_answer` (string): Ground truth answer
- `generated_answer` (string): Model's generated answer
- `is_correct` (boolean): Whether prediction is correct

## Benefits of This Structure

1. **Machine-readable**: JSON format for easy parsing
2. **Streamable**: JSONL allows processing line-by-line
3. **Timestamped**: All events have timestamps for replay
4. **Complete**: All training information captured
5. **Extensible**: Easy to add new fields
6. **Standard**: Works with standard tools (jq, pandas, etc.)
